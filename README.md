# MOAZ PROGRAMMER

واجهة أولية لمنصة تعليم البرمجة باللغة العربية، مبنية باستخدام React وVite، ومهيأة لتطويرها وربطها بخدمات خلفية.

## التشغيل محلياً

1. ثبّت Node.js (إصدار حديث).
2. افتح مجلد المشروع في الطرفية.
3. نفّذ:

```bash
npm install
npm run dev
```

4. افتح الرابط المحلي الذي يظهر في الطرفية.

## البناء والنشر

```bash
npm run build
```

ينتج مجلد `dist`. يمكن نشره على GitHub Pages أو أي استضافة مواقع ثابتة بعد ضبط مسار النشر إذا كان المستودع داخل مسار فرعي.

## ما يعمل في هذه النسخة

- واجهة عربية RTL متجاوبة مع الهاتف والكمبيوتر.
- تسجيل تجريبي بالاسم وحفظه محلياً في المتصفح.
- لوحة طالب وإحصائيات تقدم محلية.
- قائمة دروس تجريبية وتحديد الدرس كمكتمل.
- اختبار تفاعلي تجريبي.
- محرر JavaScript بسيط يعرض `console.log`.
- تبديل الوضع الليلي/النهاري.
- صفحة تواصل مع المطور عبر واتساب.

## ما يحتاج إلى استكمال قبل الاستخدام الحقيقي

- **المصادقة:** شاشة الدخول الحالية تجريبية ولا توفر حسابات آمنة أو كلمات مرور.
- **قاعدة البيانات:** التقدم والاسم محفوظان محلياً في المتصفح فقط؛ يلزم ربط قاعدة بيانات وخادم API.
- **لوحة الإدارة:** يلزم بناء صلاحيات مدير حقيقية وتوثيق آمن قبل إتاحة إدارة المحتوى.
- **المساعد الذكي:** يلزم ربط مزود AI من خلال خادم آمن؛ لا تضع مفتاح API داخل كود المتصفح.
- **المحتوى الرسمي:** الدروس الظاهرة أمثلة واجهة وليست محتوى كتاب الوزارة. يجب إدخال الكتاب الرسمي والتحقق من المنهج قبل نشر الدروس والملخصات.
- **الفيديوهات والمجتمع والإشعارات والترتيب والشهادات:** تحتاج إلى ملفات محتوى وخدمات خلفية.
- **محرر الأكواد:** النسخة الحالية لتجارب JavaScript بسيطة فقط، وليست بيئة تشغيل معزولة للأكواد غير الموثوقة.
